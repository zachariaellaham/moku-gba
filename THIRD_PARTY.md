# Third-party software

Everything in this repository is original work under the MIT licence in `LICENSE`, with the two
exceptions listed first. Nothing here is copied from a commercial game: the art, the music and the
sound effects are all generated by the scripts in `tools/`.

## Vendored in this repository

| what | where | licence |
|---|---|---|
| **doctest** by Viktor Kirilov, the unit-test framework, as a single header | `tests/host/third_party/doctest.h` | MIT |

## Needed to build, not included here

| what | used for | licence |
|---|---|---|
| **Butano** by Gustavo Valiente | the GBA framework the ROM is built against | zlib |
| **devkitARM / devkitPro** | the ARM toolchain, libgba and `mmutil` | mixed, see devkitPro |
| **maxmod** by Mukunda Johnson | the sound driver Butano uses | ISC |
| **mGBA** by Vicki Pfau (`libmgba`) | linked by the headless test harness `tests/rom/harness/mokurun.c` | MPL-2.0 |

`mokurun.c` is original code that links `libmgba` at build time. MPL-2.0 is a per-file licence: it
covers mGBA's own files, which are not redistributed here, and leaves `mokurun.c` under this
repository's licence. The harness is a development tool and is not part of the ROM.

## Generated, not authored

`tools/gen_font.py`, `gen_art.py`, `gen_chars.py`, `gen_audio.py`, `gen_patterns.py` and
`gen_missions.py` produce every asset in `graphics/`, `audio/`, `include/` and the generated
`.cpp` tables from first principles. Run any of them with `--check` to confirm the committed files
still match what the generator makes.
